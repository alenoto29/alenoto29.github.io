SEO: worth a try

Chemu Ng’ok · Dreaming / A Nation · 2025

Less repetitive work. More time for SEO.

A collection of tools for checking pages, keeping offer data current and tracking keywords. Built around the work an SEO team needs to do every week.

Observed result

After a roughly 50% drop in both clicks and impressions following the March update, these pages surpassed their pre-update levels.

Observed within a wider SEO effort; the recovery cannot be attributed to these tools alone.

What changed

Preparing pages, checking content and updating prices took a lot of manual work. I built workflows for those recurring tasks, from a page checker and reusable WordPress components to offer updates and keyword tracking.

The page checker and component library became tools the whole SEO team could use independently. Together, these processes saved a considerable amount of time and made it easier to focus on higher-priority work. Page updates still went through review before I uploaded them to WordPress.

Results

After the March search update, clicks and impressions for these pages fell by around 50%. Both have since grown past their pre-update levels. These are results I observed while working on the pages; the workflows were part of a wider SEO effort, so I can’t isolate their effect on traffic.

Under the hood

Choose a project below to see its inputs, steps and outputs. Each tool handles a different part of the process, with review before changes reach a live site.

Page checker

Input
A saved HTML page and configurable checking rules.

  1. Extract headings, readable text and links from the HTML.
  2. Check page structure, heading patterns and Italian readability.
  3. Review the findings and decide what needs editing.

Output
A JSON report with checks and findings.

The public tool checks local HTML. It does not verify facts, visit links or test the page in a browser.

Costanti / price updates

Input
The current price-constant CSV and a compatible tariff snapshot.

  1. Read the source prices and match offers to existing entries.
  2. Review changes, new offers and cases that need a decision.
  3. Generate proposed CSV updates while preserving existing references.

Output
Changed rows, new entries and a proposed full catalogue.

The tool prepares files for review. Importing them into a CMS remains a separate step.

Offer-page updates

Input
Offer data and an HTML page with a designated offers block.

  1. Validate the supplied offers and the comparison assumptions.
  2. Prepare the updated offers block while keeping the rest of the page intact.
  3. Review the preview and changes before uploading the page.

Output
A proposed HTML update and a reviewable record of the changes.

The public adaptation uses a neutral template. It does not include company components or publish to WordPress.

Keyword tracking

Input
A keyword list, a target domain and search-location settings.

  1. Collect organic search results for each keyword.
  2. Record the target domain’s position and flag incomplete or failed searches.
  3. Compare saved runs to see how positions change over time.

Output
Dated search snapshots and a local ranking dashboard.

An offline example is included. Live tracking requires your own Serper API key and an explicit request budget.

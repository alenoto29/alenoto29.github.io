04 / Paid acquisition reporting

Making disagreement visible

Chemu Ng’ok · Remembering, diptych · 2025

A shared basis for budget decisions.

I built a daily dashboard that brings advertising exports and attribution data into one view, with explicit rules for each metric. The app team uses it to monitor acquisition and inform budget allocation.

Building the view we were missing

A new app project needed a shared view of acquisition performance. Advertising spend, installs and in-app activity lived in separate exports. The attribution tool's available tier did not let us bring cost data into the same place.

My manager and I agreed to build the missing view. I implemented the dashboard with AI assistance and keep it updated. There was no existing report to replace: this was the team's first shared view of those numbers.

When the sources disagree

The key decision came from noticing that advertising platforms and the attribution tool reported different install counts for the same dates. I chose native platform exports as the reference for paid spend and delivery, keeping attributed figures in a separate, labelled view.

That distinction shaped the dashboard. Each metric needed an identifiable source and definition. Missing data also needed to remain visible: an export that had not arrived could not silently become a day with zero activity.

The pipeline turns source data into consistent daily records, calculates metrics and produces an interactive dashboard. AI helped me build it; the reporting itself runs through deterministic code.

A tool used across the team

The dashboard became a shared reference for the app team, from leadership to interns. Leadership requested additional metrics, and the team used comparisons of acquisition and in-app action costs to inform advertising-budget allocation.

That is the supported outcome: a reporting tool used in real decisions. It does not establish that reallocating the budget improved performance, and the daily view does not measure cohort profitability or the causal effect of advertising.

Under the hood

From source data to a shared view. Python normalises data from advertising and attribution platforms, calculates metrics and renders an interactive dashboard published behind access control.

Checks before combining sources. Related campaign exports are checked for matching totals. Raw source labels remain intact, while inferred joins and timezone differences carry flags.

Missing is different from zero. An absent export, no recorded activity and a recorded zero remain distinguishable. A ratio with a zero denominator is shown as unavailable.

Journalist outreach platform

Every journalist contact in one place

One shared history replaced digging through scattered spreadsheets.

What changed
Colleagues find a journalist, see who contacted them before, and update the record for the next person.
What I did
Asked PR colleagues how they choose journalists, then built the database and dashboard with AI assistance.
Who uses it
The PR team. Colleagues add and update contacts themselves.

The problem

Journalist details were spread across spreadsheets. Finding the right person, or knowing who had already been contacted, meant searching file by file.

Built for people to add to

A colleague who finds a good contact should be able to add it right away, for everyone. That's why it's a shared database with forms, and not another file.

How it works

  1. One databaseA small web app on a shared database that keeps a log of every change.
  2. ContextTools collect articles and link journalists, publishers and topics.
  3. No doublesNew journalists go in only after a duplicate check.
  4. Team accessA shared link for selected people.

The honest bit

I haven't measured the time saved or any effect on campaigns. Topics are guessed from keywords and need review. Access is one shared link, without individual accounts.
